# 🎓 CS GPT for CBSE Class 11 & 12 Computer Science

An interactive, GUI-based Python learning tool designed specifically for **CBSE Class 11 and Class 12 Computer Science** students. Built by **Adithya V**, this project packs essential syllabus programs, exam questions, code demonstrations, and data structure visualizations into a sleek, VS Code-styled GUI terminal window.

---

## 🌟 Key Features

### 📘 Class 11 CS GPT (`cs11_gpt.py`)
- **Core Fundamentals**: Odd/Even, Prime Numbers, Palindromes, Armstrong, Neon, Perfect Numbers.
- **Calculators**: Multi-term Math, Trigonometric, Inverse, Hyperbolic, Logarithms, Roots, Percentage, Class 10 Board Percentage.
- **Pattern Generators**: Character, Constant Number, and Increasing Number variations for Right-aligned Triangles, Pyramids, Diamonds, and Squares.
- **Data Types & Operations**: Detailed methods for `int`, `float`, `complex`, `str`, `list`, `tuple`, `dict`, `set`, and `bool`.
- **Built-in Modules**: Hands-on exercises for `math`, `random`, and `statistics`.
- **Sorting Algorithms**: Bubble Sort, Selection Sort, Insertion Sort, and Descending Order sorting.
- **Interactive Games**: Dice Simulator & Random Number Prediction.

### 📕 Class 12 CS GPT (`cs12_gpt.py`)
- **Functions Deep Dive**: Built-in, module, user-defined, `lambda` (map/filter), recursive, higher-order, generator (`yield`), function composition, memoization, decorators, and currying.
- **Argument Passing**: Positional, default, keyword, `*args`, `**kwargs`, positional-only `/`, keyword-only `*`, mutable default pitfalls, call by value vs call by reference.
- **Return Values**: Single/multiple returns, `None`, function-returning-functions, early return guard clauses, tuple returns, chained calls.
- **Scope & LEGB Rule**: Local, Enclosing, Global (`global` & `nonlocal` keywords), closures, variable shadowing, class vs instance scope, `UnboundLocalError`.
- **Recursion Masterclass**: Factorials, Fibonacci, Sum of Digits, GCD, Tower of Hanoi, Binary Search, String Reversal, Matrix/List recursion, AP series.
- **Exception Handling**: `try-except-else-finally`, custom exception classes, assertions, nested `try`, exception chaining (`raise...from`).
- **File Handling**:
  - **Text Files**: Reading/writing, line counting, word frequencies, character replacement, longest words, line filtering.
  - **Binary Files (`pickle`)**: Record creation, searching by roll/name, updating, deleting, sorting by marks, copy pass/fail records, merging files.
  - **CSV Files (`csv`)**: `DictWriter`/`DictReader`, `writerows`, searching passwords, filtering high scorers, sorting records.
- **Data Structures (Stack)**: List-based stack, class-based stack, string reversal, balanced parentheses, decimal-to-binary conversion, postfix expression evaluation.
- **SQL & Relational Databases**:
  - DDL & DML Commands (`CREATE`, `ALTER`, `DROP`, `UPDATE`, `DELETE`, `GROUP BY`, `HAVING`).
  - Complex SQL Queries (Joins, Subqueries, Pattern matching `LIKE`, Views, `CASE WHEN`).
  - Python-MySQL Connectivity (`mysql.connector`, parameterized queries `%s`, `commit()`, `rollback()`, `executemany()`).

---

## 💻 Tech Stack & UI

- **Language**: Python 3.8+
- **GUI Engine**: Native `tkinter` with a dark VS Code terminal theme
- **Database Driver**: `mysql-connector-python` *(optional for SQL connectivity demos)*
